# honeymoon-europe｜新婚旅行データ管理

> **重要 (2026-11-13 修正): 元の12日間画像は日本帰着を含まず、都市間移動を終日観光扱いにしていました。日本発着かつ10日間の終日観光を希望する場合は `data/itinerary-16days.json` を参照。14日間の圧縮案は `data/itinerary-14days.json`。**


**元の47スポットを削除しない**ことを大前提にした、12日間モデルの日程データです。

## 正本とファイル
- `data/itinerary-12days.json`：旅行の条件、12日分の時間割、移動手段・所要時間、夜ご飯、未訪問理由（正本）
- `data/spot-catalog.csv`：元の47件に固定IDを振った候補台帳＋パリ/モンサンミッシェル追加分
- `data/venue-rules.json`：主要施設の営業時間・休館・公式URL（確認日付付き）
- `docs/itinerary.md`：スマホでも読める全12日間の行程
- `scripts/validate-trip.mjs`：元47件の消失、ID重複、日程漏れ、夕食漏れ、予約未確定の注意書き欠落をチェック

## 重要な原則
1. `予定` から外しても `spots` から消さず `今回は見送り` と理由を記録する。
2. DAY1日本出発、DAY12パリ出発。**日本到着は通常DAY13**。
3. DAY5・7・9は都市間移動で半日観光。モンサンミッシェルのDAY10は他の観光を追加しない。
4. 基本的には市内の名所＋市場・商店街・お土産＋夕食を18時以降まで確保。
5. 時刻・営業日は旅行日付未確定のため仮。公式情報の `last_checked` と訪問日を照合して再確認する。
6. このリポジトリは公開のため、氏名・予約番号・パスポート情報・ホテル予約書など個人情報を入れない。

node scripts/validate-trip.mjs
