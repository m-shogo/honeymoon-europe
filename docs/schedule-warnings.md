# 日程変更時の休業・早閉まり警告

2026-11-22 実装。出発日変更・日別ルート追加／削除時に再計算し、ホーム・日別旅程・旅全体の注意へ表示する。予定済みの休館日は赤で強調。公式案内へリンクする。

対象は `data/schedule-rules.json` の登録済みルール。定休日、季節の最終入場、日曜のバルセロナの買物、冬季平日のモンサンミッシェル往復交通を照合する。未登録の予定は個別確認と表示する。出典と確認日はデータに保持する。

都市順とホテル11泊・14日間の標準案が前提。出発日変更には追従するが、都市ごとの宿泊数や飛行機・列車の到着時刻変更には自動追従しない。別都市の場所を日別予定へ追加すると移動確認を促す。2027年以外はルール再確認を促す。

臨時休業・予約在庫・全店舗の営業は自動取得しない。警告なしは営業保証ではない。My Mapsの自動警告やプッシュ通知ではなく、旅手帖内の表示。`booking.html` は2/1出発案の固定資料で、日付変更後は旅手帖の警告を確認する。

検証：日付変更による曜日移動、市場の日曜休業、予定追加時の休館、最終日曜例外、季節外・年外の要確認、既存保存データの互換性をテスト。画面では2/2へ変更後、2/1へ戻して2/7の市場警告を確認。旧キャッシュと新コードの混在を防ぐため配信資産の版を揃えた。
