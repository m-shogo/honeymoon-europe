# 日本発着を含む旅程の日数監査（2026-11-13）

## 以前の12日案の誤り

- DAY12にパリを出発するなら日本到着は通常DAY13。**12日間の日本発着ではない**。
- DAY5・DAY7・DAY9には都市間移動が入り、観光を終日確保できない。
- 東京→バルセロナは直行便がないため乗継が必要。同日着か翌日着かは航空券による。

## 不変の希望

- モンサンミッシェルの島と修道院は必須。
- 真実の口も必須、映画『ローマの休日』スポットとして優先。
- ゴンドラは乗れたら嬉しい任意の体験。
- 徒歩が楽しい歴史的な街並みは徒歩を優先。無理のある長距離移動は避ける。
- 商店街、市場、昼食、夕食、お土産と移動手段の明記を重視。

## 必要な予約情報

航空券（日付・往復の便名）、ホテル位置、国際線の到着/出発日、各観光地の曜日と予約枠が揃ってから、時間単位の予定を確定する。
