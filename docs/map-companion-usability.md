# 観光・生活・雨天候補とMy Mapsの連携

2026-11-22。既存の85観光候補と30生活候補を保持。新しいピンや重複レイヤーは追加していない。

## 実装

- 観光詳細に、同じ都市・半径2km以内の登録済みトイレ／食事・買出し／屋内候補を各最大3件、直線距離の近い順に表示。
- 生活候補の座標をMy Maps用の既存確認データから取り込み、IDごとの一致を検証。座標未登録・別都市・範囲外は近隣候補にしない。
- 観光地を出発点とするGoogle Maps徒歩経路、公式利用条件、雨天候補の予約詳細へ進める。
- 観光地周辺・選択都市のMy Maps表示リンク。レイヤー状態は自動変更せず、凡例での切替を案内。
- My Maps説明の先頭へ旅手帖・日程警告・レイヤー利用法・同期範囲の案内を追記。変更前の説明は `docs/evidence/map-description-before-20261122.txt` に保存。ピン・写真・レイヤーは変更していない。

## 検証と制限

距離は球面上の直線距離で、徒歩時間や実際の道の長さではない。施設の入口・橋・階段・営業時間・利用条件は別途確認。屋内中心でも市場や美術館は休業・予約制の場合がある。営業中フィルターを装わない。

サグラダ・ファミリアからトイレ・スーパー・屋内候補の表示、屋内候補の詳細切替、位置を指定した実際のMy Mapsの表示をブラウザ確認。既存説明の保持と新案内の保存を確認。

Googleのエリアダウンロード案内：https://support.google.com/maps/answer/6291838?co=GENIE.Platform%3DiOS&hl=ja

次の優先改善は、予約時刻を含む日別の余裕確認、ホテル確定後の帰路確認、26生活写真の未登録解消。写真の出典・条件と取得制限を解消してから登録する。予約番号やホテルなど個人情報は公開データへ埋め込まない。
