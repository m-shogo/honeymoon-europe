# 2027年2月：サンタンジェロ城内部とバルセロナ→パリ航空券（エールフランス往復前提）

調査日2026-11-23。参照旅程 `data/itinerary-2027-af-jan31.json`。未予約／便時刻のみ公表ダイヤから確認。

## サンタンジェロ城（Museo Nazionale di Castel Sant'Angelo）
- ローマ国立博物館当局公式：https://direzionemuseiroma.cultura.gov.it/en/museo-nazionale-di-castel-santangelo/
- 火〜日 09:00〜19:30、最終入場18:30、通常月休（2026年の第1月曜特別開館を2027にも適用するとは限らない）、一般€18/人、2人€36。特別日・変更に注意。
- ハドリアヌス帝の霊廟（2世紀）→要塞→教皇の住居→牢獄→博物館。螺旋状の通路、教皇居室のフレスコ、城壁、天使像とローマ・サンピエトロを見渡す屋上テラス。実地見学約90〜120分。
- パセット・ディ・ボルゴ（バチカンへの歴史的通路）は**別枠ガイドツアー**、通常入場だけで自由に歩けるとは限らない。公式の個別ツアー確認。
- 映画『天使と悪魔』の重要な舞台。作中の内装はセット撮影もあり、すべて実物のロケ撮影とは言えない。一次（伊映画撮影委員会）https://www.italyformovies.com/film-serie-tv-games/detail/6574/angeli-e-demoni
- ローマ2/4(木)：バチカン美術館午前（所要2〜3h）、13:30コロッセオ90分、サンタンジェロ城16:30〜18:15は**条件付き**（移動・待ち時間・疲労・日没の影響）。**フォロロマーノ内部は見送り**。2/3(水)午後は真実の口17:50閉場を優先し、城は追加しにくい。古い行程データの城内「見送り」は「希望ならフォロロマーノと入替可能」へ評価変更すべきで、ユーザーの正式選択はまだない。
- サンタンジェロ橋や城の**外観は無料で15〜25分の写真休憩**に適する。バチカンから徒歩10〜15分程度。写真好みなら屋上よりも城＋橋の外観も価値が高い。

## バルセロナ→パリ 2027/2/8(月)
- **AF1649 BCN15:00→CDG17:00**, 搭乗約2h、Air France運航であることを時刻表 https://www.flight.info/AF1649 により確認。チケット購入可能料金・空席未確認。
- **AF1549 BCN17:55→CDG19:55** も公表ダイヤに掲載 https://www.flight.info/AF1549 。パリホテル到着が夜遅くなり、翌2/9モンサン早朝に響くため AF1649 15:00推奨。
- ローマFCO→BCN 2/5(金) **Vueling VY6007 12:35→14:25** は別の域内航空会社。長距離往復のみ同じエールフランスという確定条件を維持。もし『全区間とも同じ航空会社』意図なら実現性再検討。
- Booking strategy A: AF **複数都市3セグメント**を一括検索
  1. 2027/1/31 羽田(HND)→ヴェネツィア(VCE) / AF279→AF1426経由CDG 翌2/1 11:45着
  2. 2027/2/8 バルセロナ(BCN)→パリCDG / AF1649 15:00→17:00
  3. 2027/2/12 パリCDG→羽田(HND) / AF274 22:20→翌2/13 19:55
- Booking strategy B: AF **長距離オープンジョー2セグメント** (1/31 HND→VCE、2/12 CDG→HND) の予約料金 + AF BCN→CDG 2/8単独片道の料金。大人2名、エコノミー同じブランド、受託荷物各1、諸税、座席・変更払い戻し条件同等で比較。
- **3セグメント一括が必ず安いわけではない**。国際線と欧州内路線の運賃計算・途中降機ルール・予約クラス・在庫次第。パリ2/8〜12の4泊立寄りはエールフランス公式のParis Stopover 1〜4泊対象となる可能性。https://wwws.airfrance.fr/en/information/aeroport/stopover-paris ただし旅程による対象条件と料金を確認。
- **1枚の航空券の中間区間を飛ばすと次区間が影響を受ける**：エールフランスはフライトクーポン順序利用を運送約款に規定（不遵守に追加料金・再計算）。https://wwws.airfrance.fr/en/information/legal/edito-cg-airfrance
- **価格参考（今回2/8 AF1649の販売価格ではない）** Expedia掲載の別日2/26/27などAF BCN→CDG片道**¥27,040〜/人**。今回の実額は不明。https://www.expedia.co.jp/en/lp/flight-routes/air-france-from-barcelona-intl-to-roissy-charles-de-gaulle/af/bcn/cdg
- さらにTraveloka 2027/2/8 BCN→CDG **¥6,551〜**と表示するが、**航空会社指定なし、AF1649の金額ではない**。AF希望時にはその価格で買えると誤認しない。https://www.traveloka.com/en-jp/flight/route/Barcelona-Paris.BCN.CDG
- 結論：**2パターンを同時に見積もって安くて条件良い方を選ぶ**。帰国前のフライトを既に購入してから「追加すれば安い」は期待できず、購入前の複数都市検索が重要。滞在中、バルセロナ→パリとパリ→羽田は4泊離れているので同日乗継ではない、受託荷物は2/8パリで受け取る。
