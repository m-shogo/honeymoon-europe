## 旅行中の使いやすさ（2026-11-24 v6）

6つの場面（朝ホテルで今日を見る／電波がない／タクシー・フロント／出発前に予約／次の場所へ歩く／計画に関わっていない方）でスマホ幅を操作し、出た課題を対応した。
- **今日**：各ページ上部に「今日」ボタン（旅行中は今日のページ、出発前は「出発まで◯日」）。表紙に今日・カウントダウンの帯。各日の写真の上に「今日の日程へ ↓」。スマホでは表紙写真を短く。
- **ホテル住所カード**：各日のホテル欄をタップすると、都市ごとにホテル名・住所・電話を登録でき、タクシーに見せる大きな画面（現地語「このホテルまで」＋英語）とGoogleマップを表示。端末のブラウザにだけ保存。
- **予約しなきゃリスト**（表紙）：航空券・ホテル・列車・欧州内便・ツアーと、日程の予約が必要なスポットを発売の早い順に。発売日は `BOOKING_RULES`（予約確認記録）から今回の訪問日で計算（例：グエル公園90日前→11/9ごろ、サグラダ・ファミリア約2か月前→12/8ごろ、コロッセオ30日前→1/4ごろ）。「あと◯日」は開いた日に計算。
- **予約済み✓**：リストと各日の詳細のチェックが連動（`techo:booked:<ID>`）。日程とチケット欄に「✓ 予約済み」。
- **徒歩の目安**：前のスポットから次のスポットまで、座標の直線距離×1.3・時速4.5kmで「徒歩 約◯分」。遠い場合は地下鉄・タクシー（ヴェネツィアは水上バス）を案内。街歩きの予定は歩く前提で表示。
- **オフライン**：`magazine/sw.js`（ビルドで生成）。ページとデザインは最初に開いたとき全15ページを保存、写真・フォントは見たものから保存。各日の「この日の写真も保存」、表紙の「全日の写真をまとめて保存」（385枚・約75MBの見積もり）。地図の埋め込みは通信が必要。
- 確認：ローカルでサーバーを止めた状態でDAY04・DAY11が保存済みの内容で開くことを確認。ホテルカードの登録と表示、予約済みの連動（表紙1/25に反映）、カウントダウン（68日）を確認。iPhone実機での確認は未実施。

- いま・つぎ：旅行の当日、その日のページの日程の上に、現地時刻での「いま」の予定と「つぎ」の予定（あと何分）を表示し、日程の項目を強調。1分ごとに更新。`?now=2027-02-04T16:00`（その都市の現地時刻）で試せる。
- ついでに直したこと：DAY01・DAY13（東京）の時計がパリ時間になっていたのを日本時間に。「つぎ」の行に、ページ下の前後リンクと同じクラス名 `next` を使うと表示が崩れるため `nb-next` にした。

## 写真の集め方

1. 検索語は `scripts/magazine_photo_queries.py`（移動・料理・お土産・コラージュ用）。
2. `python3 scripts/collect-magazine-photos.py` でWikimedia Commonsを検索し、ライセンスがCC BY／CC BY-SA／CC0／パブリックドメインのJPEG（幅1000px以上）だけを候補として `data/magazine-photo-candidates.json` に記録（画像は保存しない）。
3. 候補を一覧で目視し、場所・料理に合う写真の番号を `data/magazine-photos.json` の `picks` に記録。合う写真がない場合は検索語を変えて取り直すか、使わない（null）。
4. 写真は場所・料理のイメージで、撮影時期や天候は訪問時と異なる。機材の写真は実際の便の機体とは限らない。
