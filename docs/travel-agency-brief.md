# ヨーロッパ新婚旅行｜旅行会社に相談するための希望リスト

**旅行形態：** 夫婦2名／2027年1〜3月を想定（出発日は未定）  
**訪問順：** 🇪🇸 バルセロナ → 🇮🇹 ローマ → 🇮🇹 ベネチア → 🇫🇷 パリ（モンサンミッシェル日帰り）  
**日数：** 希望の観光日をすべて丸一日確保する場合、日本発着**16日間を基準**。日本→バルセロナが翌日着の場合などは17日以上を要検討。航空券・ホテル未予約。  
**旅行で重視すること：** 世界的な定番名所、映画・ドラマの舞台、街並みを歩く楽しさ、有名な商店街・市場・お土産屋、フードホール、各地の食事。街並みが魅力的で歩ける距離なら徒歩優先。遠距離の日帰りはモンサンミッシェル以外、原則入れない。

## 絶対に外したくない・できれば

- **必ず：** モンサンミッシェル（島内＋修道院）、ローマの真実の口。基本の名所であるサグラダ・ファミリア、コロッセオ、エッフェル塔、ルーブル美術館も優先。
- **できれば：** ベネチアでゴンドラ乗船（30分）。水上バスとの入れ替えでもよい。
- **映画・ドラマ：** 『ローマの休日』真実の口・スペイン階段、『甘い生活』トレビの泉、Netflix『ルパン』ルーブル美術館。映画ロケ地が街歩きの動線上にあれば寄りたい。

**歩きたい商店街・市場**：グラシア通り（Passeig de Gràcia／建築とブランド）、ポルタル・デ・ランヘル通り（Portal de l'Àngel／歩行者ショッピング通り）、ランブラス通り（La Rambla／街歩き）、ボケリア市場（食べ歩き）、サンタ・カテリーナ市場、エル・ボルン地区（個人商店・雑貨）。

**食べたいもの・夕食**：タパス、パエリア、ピンチョス、海鮮。エル・ナシオナル（複数の飲食エリア）、Cervecería Catalana、La Mar Saladaなど。

**街歩きの組み合わせ**：カサ・ミラ→カサ・バトリョ→グラシア通り／大聖堂→ゴシック地区→エル・ボルン→市場。

**映画・ドラマ**：Netflix『ルパン』のルーブル美術館（近くのポン・デザールも徒歩で可能なら）。

**遠方で今回は基本見送り**：ヴェルサイユ宮殿、ロワール古城。モンマルトルやオペラ座内部は上記スポットより優先度が低い。

## 旅行会社に相談したいポイント

1. **航空券と全日数を先に整合**：日本→バルセロナIN、パリ→日本OUT（オープンジョー）。往路の現地到着日、復路の日本着日を必ず含める。
2. **都市間移動は別日で**：バルセロナ→ローマは飛行機、ローマ→ベネチアは高速鉄道、ベネチア→パリは飛行機。空港・駅の移動や受託荷物も含めて考える。
3. **ホテルは街中・駅から便利**：バルセロナ＝カタルーニャ広場〜グラシア通り、ローマ＝モンティ〜テルミニ、ベネチア＝サンタ・ルチア駅近くの本島、パリ＝レ・アル〜パレ・ロワイヤル。
4. **歩き重視＋疲労に配慮**：街並みが魅力的なら徒歩を優先。スーツケース・坂道・長い移動・遅い帰着には鉄道・タクシーを使う。
5. **営業時間・曜日で順序変更**：ルーブル火曜休館、ボケリア市場日曜休場、リアルト魚市場日月休場、サン・マルコ寺院の日祝の見学枠など。
6. **モンサンミッシェルは終日**：TGV・バス・シャトルの往復接続を優先し、この日にほかの遠距離観光は入れない。
