# ヨーロッパ新婚旅行｜12日間の行程（モデル）

> **未予約・曜日未確定。時刻はすべて現地時間の仮置き。**

日本発着を12日間と断定することはできません。DAY12にパリを出る場合、日本到着は通常DAY13です。DAY5・7・9は都市間移動を含む半日観光であり、各都市に丸3日/丸2日滞在する計算ではありません。

## 行程

### DAY 1｜移動 — 日本からバルセロナへ

宿泊：バルセロナ（便次第）

- **便次第** 日本出発 → バルセロナ到着（便・乗継により時刻変動）｜移動：飛行機｜注意：航空券未予約。便の確定前に日中の観光を設定しない。現地到着が翌日なら観光初日を調整。
- **便次第** ホテルへ移動・チェックイン・休息｜移動：空港バス/鉄道/タクシー｜注意：空港から市街地おおむね30〜60分。夕食は到着時刻次第。
- **夕食**：便次第 到着時間に応じてホテル周辺。到着が遅ければ無理に外出しない

### DAY 2｜バルセロナ — ガウディ建築と公園

宿泊：バルセロナ

- **09:30–11:30** サグラダ・ファミリア：内部を見学｜移動：徒歩/地下鉄｜注意：日曜は10:30開場のため時刻を後ろ倒し。事前オンライン予約必須。
- **11:45–12:45** 近隣でタパスの昼食｜移動：徒歩
- **13:30–15:30** グエル公園：記念撮影と散策｜移動：タクシーまたは地下鉄＋徒歩（約25分）｜注意：坂道があるのでタクシー推奨。日時指定で予約。
- **15:30–16:00** 公園から市内のカフェ・休憩地点へ｜移動：タクシー/路線バス
- **16:00–18:00** グラシア地区でカフェ、雑貨、街歩き｜移動：徒歩｜注意：座って休む時間を確保
- **夕食**：19:00 Cervecería Catalana（タパス・モンタディート）。人気店のため行列に注意

### DAY 3｜バルセロナ — ガウディの住宅建築と買い物

宿泊：バルセロナ

- **09:00–10:20** カサ・ミラ：屋上と内部｜移動：徒歩/地下鉄｜注意：2027/1/11〜17は休館予定。その日程なら外観だけに変更
- **10:35–11:55** カサ・バトリョ：内部見学｜移動：徒歩（約10分）｜注意：日時指定予約推奨
- **12:10–13:15** グラシア通り沿いで昼食｜移動：徒歩
- **13:15–15:15** グラシア通り：ブランド・雑貨・お土産｜移動：徒歩
- **15:30–16:00** カタルーニャ広場｜移動：徒歩（約10分）
- **16:10–18:00** ポルタル・デ・ランヘル通り：商店街｜移動：徒歩（約8分）
- **夕食**：19:00 El Nacional Barcelona（タパス・魚料理・肉料理（複数の飲食エリア））。グラシア通りに戻る。約10〜20分

### DAY 4｜バルセロナ — 旧市街・市場・海辺

宿泊：バルセロナ

- **09:30–10:20** バルセロナ大聖堂｜移動：徒歩/地下鉄｜注意：日曜・宗教祝日の観光枠は14:00〜。該当時は入替必須。
- **10:30–11:20** ゴシック地区の路地と雑貨屋｜移動：徒歩（約5分）
- **11:30–12:10** サンタ・カテリーナ市場：市場見学｜移動：徒歩（約8分）｜注意：曜日・開場を要確認。閉まっていればエル・ボルン散策に変更
- **12:15–13:45** エル・ボルン地区：昼食・雑貨｜移動：徒歩（約7分）
- **14:00–14:35** ランブラス通り｜移動：徒歩（約15分）
- **14:35–15:20** ボケリア市場：軽食とお土産｜移動：徒歩｜注意：日曜休場。日曜の場合はDAY3との順序を入替
- **16:00–17:15** バルセロネータ・ビーチ：海辺を散策｜移動：地下鉄/タクシー（約25分）
- **17:15–18:00** 海沿いで休憩・夕景｜移動：徒歩
- **夕食**：20:00 La Mar Salada（魚介パエリア・フィデウア）。火曜は休み。火曜なら別の海鮮店に変更。パエリアの夕食は20時からの営業

- **14:00–14:20** スペイン階段｜移動：徒歩/地下鉄
- **14:20–14:45** コンドッティ通り：ショップ見学｜移動：徒歩（約2分）
- **15:00–15:25** トレビの泉｜移動：徒歩（約15分）
- **15:50–16:25** パンテオン（内部）｜移動：徒歩（約15分）｜注意：入場規制や宗教行事に注意
- **16:35–17:00** ナヴォーナ広場｜移動：徒歩（約8分）
- **17:15–17:45** カンポ・デ・フィオーリ広場｜移動：徒歩（約10分）｜注意：市場の営業時間ではなく広場の散策

### DAY 6｜ローマ — 古代ローマとバチカン大聖堂

宿泊：ローマ

- **12:30–13:30** 駅・カンナレージョ地区で昼食と休憩｜移動：徒歩

- **14:45–15:20** リアルト橋と大運河を撮影｜移動：徒歩（約20分）

### DAY 12｜移動 — パリ出発・帰国便

宿泊：機内（通常）

- **便次第** ホテル → パリ空港（余裕を持って移動）｜移動：空港鉄道/タクシー｜注意：国際線は通常出発の3時間前を目安に空港到着

## 必ず再確認

- 出発日を決めて曜日を確定：ルーブル火曜休館、ボケリア日曜休場、サン・マルコ寺院日祝午後見学、大聖堂の日祝時間
- カサ・ミラ2027/1/11〜17の休館に当たる場合は別日に変更か外観見学
- モンサンミッシェルTGVとバスの実接続、島内シャトルと修道院最終入場を再検証
- 飛行機移動日（DAY5/9）の午後観光は到着時刻次第で削減し、削除した候補は台帳に残す
- 日本着を12日以内にするか確認。現行計画はDAY12パリ出発・通常DAY13日本着
- 各施設公式予約URLを確認。料金・営業時間は訪問日と季節で変わる
- 海鮮店La Mar Saladaは火曜休み、同日なら別店へ
- 大きな荷物を持って旧市街を歩かず、ホテルかロッカーへ預ける
- 1時間のルーブル館内鑑賞には入退場・保安検査の余裕を別途設ける

## データの責務

- `data/itinerary-12days.json` を唯一のスケジュール元データとする。
- `data/spot-catalog.csv` はスポットID・名称・都市・予定状態を一覧化した派生データ。元の47件はID固定で保持。
- `data/venue-rules.json` は営業時間・休館・予約・公式URL（確認日付き）。
- このMarkdownとCSVはJSONから同時生成して整合性を取る。編集したら `node scripts/validate-trip.mjs` を実行する。
- 営業時間や移動時間は固定の保証値ではなく、訪問日が決まってから必ず公式確認する。
