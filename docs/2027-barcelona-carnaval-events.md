# 2027年バルセロナ・カーニバル（Carnaval / Carnestoltes）とシッチェス（2026-11-15調査）

## 重要な違い
- **Carnaval de Barcelona**：バルセロナ市内の各地区・自治会・文化センターによる仮装パレード（Rua）、Arribo（カーニバル王の到着）、Taronjada（オレンジ色の風船・紙吹雪）、地域イベント。**市内に常設される巨大な中央パレードではなく、地区別に日時・会場が分散**。
- **Carnaval de Sitges**：バルセロナ中心から近郊鉄道R2 Sudで約40分の海辺のシッチェスで、派手な山車と大規模な夜の仮装パレードを開催。**バルセロナ市内のイベントとは別の祭り**。お祭りの豪華さを重視するとこちらが本命になるが、別都市への往復と夜遅い帰宅が必要で、サグラダやガウディ観光の優先度を落とさないよう注意。

- ユーザーの**2/1(月)羽田発**プランでは、バルセロナ到着は**2/6(土)14:25**、市内ホテルに概ね16時頃着予定。ラ・サグレラ16:30には遅れる可能性大。18時からのグラシア地区パレードが正式に確認できれば、到着日夕方に寄る候補。
- **2/7(日)はグエル公園＋カサ・バトリョの既存観光日**。夜にシッチェスへ出かける案は別都市への約40分片道移動と、夜の帰路混雑・列車運行・翌朝への影響がある。**祭り目的の遠方移動を固定せず、公式時刻表公表後の任意オプション**として扱う。
- 2/8(月)朝はサグラダ・ファミリア予約を第一優先、通常のバルセロナ観光はカーニバルのために削らない。
